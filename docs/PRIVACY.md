# Privacy Policy / 隐私政策

Desktop Panel is a local-first desktop notepad. This policy describes what data the
application handles. / Desktop Panel 是一款本地优先的桌面记事应用，本政策说明其数据处理方式。

## What we collect / 我们收集什么

**Nothing. / 不收集任何数据。**

The application has no accounts, no telemetry, no analytics, and no crash-report
upload. Your notes, drafts, doodles, and settings are stored **only on your own
device**: / 应用没有账号、遥测、统计或崩溃上报。笔记、草稿、涂鸦与设置**仅保存在你自己的设备上**：

- Settings, drafts, assets: `%APPDATA%\desktop-panel\`（Windows）
- Your documents: saved to locations you choose (default: your own directories)

## Network access / 网络访问

The only network activity is the **update check** (installed version): the app
contacts GitHub Releases (`api.github.com` / `github.com`) to download update
metadata and packages. No personal data is included in these requests, and no
other connections are made. / 唯一的网络行为是**更新检查**（安装版）：访问 GitHub
Releases 下载更新元数据与安装包，请求不包含个人数据，无其他连接。

## Contact / 联系方式

Questions about privacy: [open an issue](https://github.com/r56661828-cloud/desktop-panel/issues).
隐私问题请通过仓库 Issue 联系。

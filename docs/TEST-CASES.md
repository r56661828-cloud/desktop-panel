## 1. 测试策略与分层

| 层级 | 手段 | 覆盖 | 说明 |
| --- | --- | --- | --- |
| L1 开发自验 | vitest 单元断言（非交付测试，开发期自验） | md 往返一致性样例集、涂鸦 JSON 编解码、序列化规则 | 见技术方案 7.1，作为用例 TC-M3-09x 的自动化前置 |
| L2 E2E 冒烟 | Playwright `_electron` 驱动 | 唤醒/收起、新建-编辑-保存主链路、多标签切换 | 关键链路可回归，随 M1 起维护 |
| L3 人工功能测试 | 本文档用例手工执行 | 全部模块 | 主力手段，Electron 全局快捷键/置顶/托盘难以完全自动化 |
| L4 专项 | 手工 + 脚本辅助 | 性能、兼容性（HiDPI/多显示器）、可靠性（崩溃/断电式杀进程） | 按里程碑 M4 执行一轮 |

**环境基线**：Windows 10 22H2 与 Windows 11；1920×1080（100%）与 2560×1440（150% HiDPI）两套显示配置；双显示器组合场景单独标注。测试数据目录使用独立临时目录，不污染真实文档。

**用例优先级**：P0 = 冒烟必过，阻塞发布；P1 = 核心功能完整；P2 = 边界与体验。

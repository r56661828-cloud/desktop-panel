## 1. 背景与目标

### 1.1 背景

用户在日常工作中经常需要一个「随手记、随手看」的轻量入口：

- 想快速记一段文字 / 贴一段代码 / 画一个示意图，而不想去打开庞大的笔记软件或 IDE；
- 需要时希望内容**悬浮在当前工作窗口之上**（钉住），边看资料边记录，不被遮挡；
- 希望支持 Markdown 记录结构化内容，同时保留普通文本的简单性。

### 1.2 产品目标

打造一款**快捷键唤醒、可钉住置顶、轻量好用的桌面速记面板**，覆盖「记录（文字/Markdown）→ 标注（格式/涂鸦）→ 保存/再编辑」的完整闭环。

### 1.3 非目标（本期不做）

- 多面板实例、多窗口；
- 云同步、多端协作；
- macOS / Linux 适配（后续版本评估）；
- 图片 OCR、语音输入；
- 插件系统。

## 2. 用户与核心场景

目标用户：开发者、产品/运营等需要高频速记与临时标注的桌面重度用户。

| # | 场景 | 描述 |
| --- | --- | --- |
| S1 | 快捷速记 | 正在看文档，按 `Ctrl+Shift+Q` 唤起面板，快速记录一段文字，`Ctrl+Shift+Q` 或 `Esc` 收起 |

| S6 | 涂鸦标注 | 画曲线、直线、箭头、圆圈等插入笔记；事后可双击涂鸦重新进入编辑 |

## 3. 需求分析：关键设计决策

### 3.1 Markdown 与富文本的统一（对应需求 4 / 8）

Markdown 语法本身**不包含**下划线、字体颜色等富文本能力，两条需求存在冲突。决策（已确认）：

- 编辑器采用**所见即所得（WYSIWYG）Markdown 编辑器**：用户像用 Word 一样直接排版，底层将内容序列化为 Markdown 存储；
- Markdown 标准不支持的格式（下划线、颜色），序列化时以**内嵌 HTML** 写入 `.md` 文件（如 `<u>文字</u>`、`<span style="color:#ff0000">`），保证文件仍是合法 Markdown，其他编辑器可兼容打开（扩展格式在纯 md 阅读器中降级显示，已确认可接受）；
- 纯文本（`.txt`）模式下工具栏降级：只保留纯文本编辑，不提供格式化能力（避免把 HTML 标签写进 txt）。

### 3.2 涂鸦的存储与再编辑（对应需求 9，已决策：需可再编辑）

涂鸦采用**编辑区上方的画布覆盖层**实现，落盘采用「位图 + 矢量数据」双文件方案：

- 用户进入「涂鸦模式」后，光标变为画笔，在面板上直接绘制；
- 「完成」时生成两个文件，存放在文档同目录 `./assets/` 下：
  - `doodle-<时间戳>.png`：透明底位图，用于文档内的正常渲染与第三方工具兼容；
  - `doodle-<时间戳>.json`：矢量笔画数据（每笔的工具类型、颜色、粗细、坐标点序列），用于**再次编辑**；
- 文档中以 Markdown 图片语法引用 PNG；再次编辑时（双击涂鸦图片），应用读取同名 JSON 还原笔画，重新进入涂鸦模式，保存后替换原图与数据；
- 若 JSON 丢失（如仅分享了 md 文件本身），涂鸦退化为静态图片，不影响阅读。

### 3.3 「钉住」的语义（对应需求 3，已决策）

- **未钉住（默认）**：面板是**普通桌面窗口**——失去焦点后被获得焦点的应用正常遮挡，遵循常规桌面端窗口交互；
- **已钉住**：面板**始终处于最高层级**——即使 Alt+Tab 切换到其他应用，面板依然置顶显示，且失焦不改变其层级；
- 钉住是一个**开关**：标题栏图钉图标，开/关两种状态，鼠标悬浮显示 tooltip：
  - 未钉住：「未钉住：普通窗口，可被其他应用遮挡」；
  - 已钉住：「已钉住：面板始终置顶（切换应用后仍在最前）」。

### 3.4 多标签文档模型（对应需求 6/7，已决策：支持多标签）

- **单窗口、多标签**：所有文档都在同一个面板窗口内以标签页形式打开，**不另开窗口**；
- 每个标签独立持有一份文档状态：文件路径、内容、脏标记、编辑模式（md/txt）、光标与滚动位置；
- 新建标签默认进入未命名文档（`未命名-1.md`、`未命名-2.md` …），Ctrl+S 时弹出系统保存对话框；
- 打开已有文件在新标签中打开；若该文件已在某个标签中打开，则聚焦该标签而非重复打开。

## 5. 功能需求详述

### 5.1 M1 全局快捷键唤醒

- **FR-1.1** 应用启动后注册全局快捷键 `Ctrl+Shift+Q`（Windows）。
- **FR-1.2** 按 `Ctrl+Shift+Q` 切换（toggle）面板：显示 → 隐藏，隐藏 → 显示，并自动聚焦当前活动标签的编辑区。
- **FR-1.3** 面板显示时定位在屏幕居中偏上位置（视觉重心），并记住用户上次手动拖动后的位置，下次唤醒恢复。
- **FR-1.4** 快捷键注册失败（被其他应用占用）时：托盘气泡提示用户，并引导进入设置页修改快捷键（设置页落地前的降级路径：托盘菜单点击唤起）。
- **FR-1.5** 应用启动方式：开机自启默认关闭，可在设置中开启；面板关闭（隐藏）不退出应用（驻留托盘），托盘菜单提供「退出」。

### 5.2 M2 面板窗口

- **FR-2.1** 面板尺寸默认约 720 × 560 px，支持拖拽右下角缩放，最小尺寸 400 × 300，尺寸与位置持久化。
- **FR-2.2** 层级行为（对应 3.3）：
  - 未钉住：普通窗口层级，失焦后被获焦应用正常遮挡；
  - 已钉住：`alwaysOnTop` 生效（floating 及以上级别），失焦后保持置顶，Alt+Tab 切换应用后面板仍在最前。
- **FR-2.3** 无边框窗口（frameless），自绘标题栏：左侧为活动标签的文件名与脏标记 `●`，右侧为操作区（钉住、涂鸦、打开、保存、收起）。
- **FR-2.4** 钉住按钮为图钉图标，开关两种状态，tooltip 见 3.3；钉住状态跨会话持久化（记住用户偏好）。
- **FR-2.5** 失焦无特殊行为（普通窗口语义）；隐藏面板仅通过 `Ctrl+Shift+Q`、`Esc` 或标题栏收起按钮。
- **FR-2.6** 面板支持拖动：按住标题栏空白处拖动，记忆位置。
- **FR-2.7** 按 `Esc` 隐藏面板（未保存内容遵循 5.9 保护策略）。

### 5.3 M3 Markdown 编辑（WYSIWYG）

- **FR-3.1** 支持常用 Markdown 语法的所见即所得编辑与渲染：标题（H1–H6）、粗体、斜体、行内代码、代码块、引用、有序/无序列表、任务列表、分割线、链接、图片。
- **FR-3.2** 支持表格（对应需求 5）：工具栏可插入 N×M 表格；支持表格内编辑、增删行列、对齐；WYSIWYG 呈现，底层以 Markdown 管道表语法存储。
- **FR-3.3** 快捷语法输入：如 `# ` 转标题、`- ` 转列表、``` ``` ``` 转代码块、`| ` 辅助建表。
- **FR-3.4** 模式切换：支持「编辑（WYSIWYG）」与「源码（Markdown）」两种视图切换（源码视图 P1）。
- **FR-3.5** 序列化：保存时导出为 Markdown 文本；对下划线、颜色等扩展格式以 HTML 内嵌（见 3.1）。
- **FR-3.6** 打开 `.md` 文件时正确解析渲染（含表格、内嵌 HTML 扩展格式）。

### 5.4 M4 纯文本编辑

- **FR-4.1** `.txt` 文件以纯文本模式打开：等宽/常规字体、无格式渲染、不注入任何标签。
- **FR-4.2** 新建标签时可选择文档类型（Markdown / 纯文本），默认 Markdown。
- **FR-4.3** 纯文本模式下格式工具栏置灰不可用；涂鸦插入功能不可用（提示用户改用 Markdown 标签）。

### 5.5 M5 保存

- **FR-5.1** `Ctrl+S` 保存**当前活动标签**的文档；该文档无对应磁盘文件时弹出系统「另存为」对话框，默认文件名 `未命名-1.md`（序号递增），默认路径为上次使用目录（首次为 `~/Documents`）。
- **FR-5.2** 已有磁盘文件的文档，Ctrl+S 直接覆盖保存，不打断（可配置是否弹确认，默认不弹）。
- **FR-5.3** 涂鸦文件（PNG + JSON）保存至文档同目录 `./assets/` 下，文档内以相对路径引用，保证文档可移动。
- **FR-5.4** 保存成功后右下角轻提示（toast）「已保存」，活动标签脏标记清除；保存失败（路径只读等）给出错误 toast 并保留脏状态。
- **FR-5.5** 支持「另存为」（Ctrl+Shift+S）：为当前文档选择新路径，原文件保持不动。

### 5.6 M6 打开与再编辑

- **FR-6.1** 标题栏「打开」按钮或 `Ctrl+O` 唤起系统文件对话框，过滤 `.md / .markdown / .txt`；支持一次多选，多选时批量开新标签。
- **FR-6.2** 打开的文件在新标签进入可编辑状态；若该文件已在某个标签打开，聚焦该标签（FR-10.3）。
- **FR-6.3** 最近打开文件列表（托盘菜单 + 面板内下拉，最多 10 条）（P1）。
- **FR-6.4** 打开新文件不影响其他标签的未保存状态（各标签独立）。
- **FR-6.5** 对外部程序修改过的文件做检测：面板隐藏期间文件被外部变更，重新唤起时在该标签内提示「文件已在磁盘上被修改，重新加载 / 保留我的版本」。

### 5.7 M7 富文本格式化

- **FR-7.1** 选中文本后可通过工具栏或快捷键设置：
  - 加粗 `Ctrl+B`、斜体 `Ctrl+I`、下划线 `Ctrl+U`、删除线 `Ctrl+Shift+X`、行内代码 `Ctrl+E`；
  - 字号：预设档位（12/14/16/18/20/24 px）作用于选区；
  - 字体颜色与背景色：预设色板（8–10 色）+ 自定义取色器。
- **FR-7.2** 工具栏跟随选区浮动显示（类 Notion），或在标题栏下方固定一栏（实现取其一，倾向浮动栏，视觉更轻）。
- **FR-7.3** 清除格式按钮：一键去除选区全部格式。
- **FR-7.4** 上述格式中 Markdown 不支持的部分按 3.1 的 HTML 内嵌方案落盘。

### 5.8 M8 涂鸦（矢量存储，可再编辑）

- **FR-8.1** 标题栏「涂鸦」按钮或 `Ctrl+D` 进入涂鸦模式：编辑区上方覆盖透明画布，光标变为画笔，禁止文字编辑。
- **FR-8.2** 画笔工具：自由曲线（默认）、直线、箭头、矩形、圆/椭圆、橡皮擦；画笔颜色（同 FR-7.1 色板）与粗细（3 档：细/中/粗）可选。
- **FR-8.3** 支持撤销/重做当前涂鸦笔画（Ctrl+Z / Ctrl+Y，仅涂鸦会话内）。
- **FR-8.4** 「完成」：将画布内容按 3.2 双文件方案落盘——透明底 PNG（渲染用）+ 矢量 JSON（再编辑用），文档中插入图片引用，退出涂鸦模式。
- **FR-8.5** 「取消」：丢弃本次涂鸦，不产生任何文件。
- **FR-8.6** 涂鸦模式下 Esc 等价于取消。
- **FR-8.7** 涂鸦底色透明，仅落笔部分进入 PNG（避免白底遮挡文档）。
- **FR-8.8** **再编辑**：双击文档中的涂鸦图片（或选中后点击涂鸦按钮），读取同名矢量 JSON 还原全部笔画并重新进入涂鸦模式；「完成」后替换原图与 JSON（保留原文件名），文档内引用不变。
- **FR-8.9** 矢量 JSON 缺失时，双击涂鸦图片提示「该涂鸦不可再编辑（缺少笔迹数据）」，仅作静态图片展示。

### 5.9 未保存内容的保护策略

- **FR-9.1** 面板隐藏（`Esc`/`Ctrl+Shift+Q`/收起按钮）时**不丢弃内容**：所有标签的未保存内容自动暂存到本地草稿（应用数据目录），下次唤醒自动恢复，各标签脏标记保留。
- **FR-9.2** 主动退出应用（托盘退出）且存在未保存修改的标签时，弹出确认：保存 / 不保存 / 取消。
- **FR-9.3** 草稿崩溃恢复：应用异常退出后再次启动，自动恢复全部标签草稿。
- **FR-9.4** 关闭单个有未保存修改的标签：弹出确认（保存 / 不保存 / 取消），见 FR-10.5。

### 5.10 M10 多标签

- **FR-10.1** 标签栏位于标题栏下方：每个标签显示文件名（未保存时带 `●`）与关闭按钮 `×`；标签栏右侧提供「+」新建标签（`Ctrl+T`）。
- **FR-10.2** 每个标签独立文档状态（文件路径、内容、脏标记、md/txt 模式、光标与滚动位置），切换标签时完整恢复。
- **FR-10.3** 打开文件在新标签打开；若文件已在某标签打开则聚焦该标签，不重复打开。
- **FR-10.4** 标签切换快捷键：`Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换；`Ctrl+PgUp` / `Ctrl+PgDn` 相邻切换。
- **FR-10.5** 关闭标签：点击 `×`、`Ctrl+W` 或鼠标中键；有未保存修改时弹确认（保存 / 不保存 / 取消）。
- **FR-10.6** 关闭最后一个标签时不退出应用，新建一个空白标签兜底；面板仍在，可继续使用或收起。
- **FR-10.7** 标签数量多时标签栏横向滚动或收缩标签宽度（最小可读宽度），不换行、不撑破面板。
- **FR-10.8** 拖拽标签调整顺序（P1）。

## 6. 交互流程（关键链路）

### 6.1 唤醒与收起

```
[任意界面] --Ctrl+Shift+Q--> 面板显示并聚焦（恢复各标签草稿内容）
Esc / Ctrl+Shift+Q / 收起按钮 --> 面板隐藏（内容已暂存，脏标记保留）
未钉住：点击面板外 --> 面板被正常遮挡（普通窗口行为，不自动隐藏）
已钉住：Alt+Tab 切走 --> 面板仍置顶显示
```

### 6.2 新建 → 编辑 → 保存

```
Ctrl+T / 「+」 --> 新标签「未命名-1.md」（WYSIWYG 空文档）
  --> 输入内容（md 语法 / 工具栏格式化 / 涂鸦插图）
  --> Ctrl+S --> 另存为对话框 --> 选择路径 --> 写盘（PNG+JSON 写入 ./assets/）
  --> toast「已保存」，该标签脏标记清除
```

### 6.3 打开 → 编辑 → 保存

```
Ctrl+O / 打开按钮 --> 文件对话框（.md/.txt，可多选）
  --> 每个文件开新标签（已打开的聚焦原标签）
  --> .md 走 WYSIWYG 渲染；.txt 走纯文本模式
  --> 编辑（该标签出现脏标记 ●）
  --> Ctrl+S 直接覆盖保存（仅活动标签）
```

### 6.4 涂鸦创建与再编辑

```
Ctrl+D 进入涂鸦模式 --> 绘制（曲线/直线/箭头/圆…，可撤销） --> 完成
  --> PNG + JSON 写入 ./assets/，文档插入图片
……
双击文档中涂鸦图片 --> 读取 JSON 还原笔画 --> 重新进入涂鸦模式
  --> 修改后「完成」--> 替换原图与 JSON（文件名不变）
```

## 7. 非功能需求

| 类别 | 要求 |

## 10. 验收要点（摘要）

1. `Ctrl+Shift+Q` 在任意前台应用下均可唤醒/隐藏面板，多标签内容与脏标记完整恢复；
2. **层级**：未钉住时面板失焦后被其他应用正常遮挡；点击图钉钉住后，Alt+Tab 切换到任意应用面板仍置顶；取消钉住恢复普通层级；图钉悬浮 tooltip 文案正确且状态跨会话记忆；
3. **多标签**：Ctrl+T 新建、Ctrl+Tab 切换、Ctrl+W 关闭；各标签独立保存与脏标记；同一文件不重复开标签；关闭最后标签不退出应用；
4. 新建文档录入标题/列表/表格等内容，Ctrl+S 另存为 `.md`，用第三方 Markdown 工具打开渲染一致（含表格与扩展格式降级可读）；
5. 打开已有 `.md`/`.txt` 可编辑并保存；`.txt` 中不出现任何 HTML 标签；
6. 选中文本可设置下划线、删除线、字号、颜色，保存后重开显示一致；
7. **涂鸦**：可画曲线/直线/箭头/圆圈，完成后生成透明底 PNG 与矢量 JSON；双击图片可还原笔画再编辑并替换；删除 JSON 后双击给出不可再编辑提示；
8. 面板隐藏不丢内容，异常退出后全部标签草稿可恢复；关闭有未保存修改的标签有确认拦截。
